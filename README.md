# Vision-based-Post-composition-camera-angle-retention-system-for-film-production
The complete source code developed for this thesis—including the computer vision pipeline, the hardware telemetry integration, and the web-based user interface—is publicly available. The repository also contains the 3D CAD models (STL and STEP files) designed for the custom device enclosure. 

September 2026, author:Jin Weijian Victor Chen

To run the pipeline:
Laptop : **python3 puente.py --live --udp-port 5005**
Pi : **python3 main.py --setup --headless --telemetria 192.168.100.166:5005** 
Visit **http://localhost:8080**

Ip adresses need to be adapted in order to function.
